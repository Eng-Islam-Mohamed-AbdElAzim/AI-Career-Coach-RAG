This is an AI-Career-Coach where you input in your resume and the AI searches the available careers and chooses the most suitable 
Career direction for you while telling you what skills you are missing and a roadmap to improve on it


🔹 AI Career Coach*
(RAG + Chains + Output Parser)

*Idea:*
* Help users choose the most suitable career path.

*Input:*
* CV
* Skills
* Experience
* Target Role

*RAG:*
* Job Descriptions
* Learning Roadmaps
* Industry Requirements

*Chains:*
* Analyze CV
* Extract Skills
* Compare with Job Requirements

*Output Parser:*
* Current Skills
* Missing Skills
* Recommended Roadmap
* Suggested Jobs
* Improvement Plan
